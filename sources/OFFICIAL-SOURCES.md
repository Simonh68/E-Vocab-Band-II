# Official source references — E‑Vocab Band II

This repository is intended to use the Israeli Ministry of Education's official English curriculum as the authoritative source for Lexical Band II.

## Primary source: Lexical Band II

- **Title:** LEXICAL BAND II — JUNIOR HIGH SCHOOL
- **Authority:** State of Israel — Ministry of Education, Pedagogical Secretariat — Language Department, English Language Education
- **Edition/date stated in the document:** November 2020
- **Official Ministry PDF:** https://meyda.education.gov.il/files/Mazkirut_Pedagogit/English/CurriculumFilesAugust21/LexicalBand2.pdf
- **Current Ministry curriculum context (Junior High / Basic User II – A2):** https://pop.education.gov.il/tchumey_daat/english/chativat-beynayim/curriculum/basic-user-a2/

## Curriculum framework

- **Title:** English Curriculum 2020
- **Official Ministry PDF:** https://meyda.education.gov.il/files/Mazkirut_Pedagogit/English/Curriculum2020.pdf

## Copyright / repository note

The Lexical Band II document states that no part of the curriculum may be reproduced, transmitted, translated, or stored in an information storage or retrieval system without prior written permission from the Ministry of Education. For that reason, this public repository stores the official source references rather than a copied Ministry PDF unless permission to reproduce/store it is confirmed.

## Data-use note

For the E‑Vocab Band II project, vocabulary data should be checked against the official Lexical Band II source and kept distinct from the separate Module E Lists A–D dataset.

The same spelling may appear in more than one source occurrence. Each occurrence must keep record-level English and Hebrew sense metadata plus links to the other serial numbers; it must not be merged or reinterpreted from spelling or POS alone. See [`data/RECORD-SENSES.md`](../data/RECORD-SENSES.md).
