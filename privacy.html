E‑Vocab Band II

מדיניות פרטיות

היישום תוכנן ללא חשבונות תלמידים וללא איסוף תשובות או ציונים.

Privacy Policy

The application is designed without student accounts and does not collect answers or scores.

מידע שנאסף בידי הפרויקט

אין הרשמה, טופסי זיהוי, פרסום, כלי אנליטיקה, פיקסלים או עוגיות מטעם הפרויקט. לא נוצרים פרופילי תלמידים ולא נשמרת פעילות למידה בשרת.

Information collected by the project

There is no registration, identification form, advertising, analytics, tracking pixel or first-party cookie. No student profile is created and no learning activity is stored on a server.

תכונות דפדפן ואירוח

העתקת קישור כותבת כתובת ציבורית ללוח המכשיר. ההקראה מופקת באמצעות מנגנון הדיבור של הדפדפן או המכשיר. האתר מאוחסן ב‑GitHub Pages, ו‑GitHub עשויה לעבד נתונים טכניים לפי מדיניותה.

Browser features and hosting

Copy link writes a public URL to the device clipboard. Speech is produced by the browser or device. The site is hosted on GitHub Pages, and GitHub may process technical request data under its own policy.
